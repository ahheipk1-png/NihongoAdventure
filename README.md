# Kana Quest

A Japanese learning game for kids. Twelve topics — hiragana, katakana, kana conversion,
numbers, animals, days of the week, verbs, nouns, adjectives, greetings, JLPT N5 vocabulary
and grammar — with a kanji level every fifth level.

Every level assigns its own game (Match, Word Building, Memory Pairs, Fruit Basket, Fishing Pond),
and every game runs on the same rule: power drains constantly, right answers refill it, and you
pass by hitting the quota before it runs out.

One self-contained HTML file, no build step. Open `index.html` in any browser.
Profiles and progress are saved in the browser's local storage.
